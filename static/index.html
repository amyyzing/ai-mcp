    UNDER THE HOOD
    Recovery, with context.
    This is a real interface to the pinned luau-vmp-deobf 0.5.2 engine, not an AI-generated approximation of your code.
    What is supported?
    Supported Luraph v14.x loader families, including the upstream v14.7 regression families. A version label alone does not guarantee compatibility. Ordinary Luau and other obfuscators, including WeAreDevs, may be rejected.
    Full recovery or strict capture?
    Full recovery permits a bounded, isolated bootstrap decoder to recover staged data. Strict capture prevents that decoder stage and can stop at an intermediate loader. The pipeline does not invoke the final application.
    What does a result prove?
    Decoded source is retained when present; otherwise the engine emits structural Luau and an instruction view. Compilation does not prove behavioral equivalence. Original names and comments cannot be promised. This release does not implement the proposed advanced restructuring pipeline.
    Where does my code go?
    Only to this Railway service. Remote lua.expert uploads are disabled. Job files are temporary; results stay in server memory for up to 30 minutes, subject to capacity. Refreshing the page clears this workspace. Deployments also clear results. Use code you own or are authorised to inspect.
